# Moroccan administrative geography

The seed data comes from the Haut-Commissariat au Plan bilingual RGPH 2024 workbook. The reference date is **1 September 2024**. HCP published the accompanying release on **7 November 2024**. The 12-region administrative structure originates in decree 2-15-40 of 20 February 2015. [HCP release](https://www.hcp.ma/Population-legale-du-Royaume-du-Maroc-repartie-par-regions-provinces-et-prefectures-et-communes-selon-les-resultats-du_a3974.html) · [HCP workbook](https://www.hcp.ma/file/242341/) · [Official decree listing](https://aute.gov.ma/affaires-juridiques-et-foncieres/)

The snapshot in `backend/database/seeders/data/hcp-rgph-2024.json` contains the workbook's 12 regions, 1,503 communes, and 205 named arrondissements and urban centers. The workbook SHA-256 is `7e9d3d402cc2fd0d9c4fc941c4f23c6a5e5ddcbefbba80b7540267f8e2728dca`. Population and household figures were omitted.

The extraction uses workbook columns A and F for French and Arabic names and column G for the geographic code as stored. It takes administrative region rows without urban or rural breakdown labels, commune rows nested under their region, and arrondissement or urban-center rows under the immediately preceding commune. The extract validates each locality's geographic code prefix against that parent. Administrative label prefixes and footnote markers were removed from display names. The application calls the commune-level table `cities` and includes rural communes to cover shop registrations outside cities. Neighborhood coverage follows the source and is partial.

Run `php artisan db:seed --class=MoroccoGeographySeeder` after migrations. Re-running the seed inserts missing official records and preserves existing IDs, administrative edits, and activation flags. Verified administrators can add or correct records through the dashboard using bilingual names, a source URL, and a source date. A record's code and parent are immutable after creation. Inactivate outdated records to preserve existing shop references.
